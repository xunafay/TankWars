# Basis
- Een tank kan bewegen in 4 richtingen (N, O, S, W)
- Een tank heeft een weapon
- Een weapon kan bewegen in 8 richtingen (N, NO, O, SO, S, SW, W, NW)
- Een tank kan schieten
- Wanneer een tank geraakt word verliest deze health.
- Wanneer een tank health 0 heeft is deze dood en blijft deze staan op de plaats waar die dood is gegaan.
